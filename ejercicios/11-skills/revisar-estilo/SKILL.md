---
name: revisar-estilo
description: Revisa un archivo Java según las buenas prácticas de la cátedra. Usar cuando se pida revisar el estilo o las buenas prácticas de un archivo.
---

1. Leer `docs/buenas-practicas.md` y el archivo indicado.
2. Por cada incumplimiento, una fila:

   | Línea | Mandamiento | Problema | Sugerencia |
   |---|---|---|---|

3. Solo problemas que puedan señalarse en una línea concreta. Sin elogios.
4. Cerrar con el mandamiento más incumplido.

No editar el archivo.
